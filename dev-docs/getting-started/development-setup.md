# Development Setup

Prerequisites and environment configuration for Valtimo development.

## Prerequisites

- **Java** — see `.java-version` in the repository root
- **Node.js** — see `frontend/package.json` engines field
- **Docker Desktop** — for running backend services (databases, Keycloak, RabbitMQ)

## Quick Start

See the main repository README for build and run commands.

For plugin development specifically, see [Developing a Plugin](../external-plugins/develop-a-plugin.md#prerequisites).
