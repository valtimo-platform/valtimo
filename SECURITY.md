# Security Policy

Security is a top priority at Ritense. We are committed to maintaining the security of our products and protecting our users.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this product, please follow the responsible disclosure guidelines outlined in our central security policy.

**[Ritense Security Policy](https://github.com/ritense/security/blob/main/SECURITY.md)**

Please do not report security vulnerabilities through public GitHub issues.

## Security Policy

This repository follows the central Ritense Security Policy, which provides information about vulnerability reporting, responsible disclosure, and security-related procedures.

For the latest security guidelines and reporting instructions, please refer to:
