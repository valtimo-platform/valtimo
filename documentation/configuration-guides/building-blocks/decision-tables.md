# Decision tables

The Decision tables tab manages DMN decision tables included in the building block.

## Decision table list

Shows all decision tables that are part of this building block. Decision tables allow you to define business rules in a tabular format.

## Adding a decision table

Click **Add** to create a new decision table. The DMN modeler allows you to:

- Define input columns (conditions)
- Define output columns (results)
- Add rules as table rows
- Configure hit policy

## Using decision tables

Decision tables can be invoked from processes using the DMN evaluate task. They can reference data from the building block's document schema.
