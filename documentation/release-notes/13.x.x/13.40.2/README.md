## Bugfixes

* **The application stays stable when users reload or close their browser**

  Reloading or closing the browser no longer makes the application slowly run out of memory.


* **A slow or lost connection no longer holds up other users**

  A user with a slow or lost connection no longer delays the processing of cases and tasks for other users.


* **Fewer false errors in the application logs**

  A user closing their browser while a page is loading no longer shows up as an error in the application logs.
