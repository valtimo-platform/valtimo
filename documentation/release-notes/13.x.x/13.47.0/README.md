## Enhancements

### The task panel in a case keeps the width you give it

The panel on the right of a case can now be dragged wider or narrower while the task list is shown, not only
while a task is open. The width you set is remembered for you across all case types and after logging in again.

### Forms in the case side panel stay open while you switch tabs

A form opened in the panel on the right of a case — a start form launched from the **Start** menu, or a task
form — now stays open and keeps everything you have entered while you move between tabs, including tabs that do
not show the task list. The form closes only when you close it yourself or submit it. Previously a start form
closed as soon as you switched tabs, and a task form could disappear and reset its contents.
